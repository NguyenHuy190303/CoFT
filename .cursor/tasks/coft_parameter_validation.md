## 🧠 **CoFT Impact Analysis**

### **Answer: CoFT affects BOTH learning phases differently**

#### **Self-supervised learning:**
- CoFT adds frequency contrastive learning parallel to temporal
- Only contrastive losses, no co-training interference
- Relatively stable impact

#### **Supervised learning (ft_1p mode):**
- CoFT adds 4 loss components:
  - Temporal contrastive loss
  - Frequency contrastive loss  
  - **Co-training loss** (cross-domain pseudo-labeling)
  - Supervised classification loss
- **High λ_cotraining**: Pseudo-labels conflict with ground truth → poor accuracy
- **Low λ_cotraining**: Supervised loss dominates → better accuracy

### **Root Cause:**
```python
total_loss = temporal_loss + frequency_loss + cotraining_loss + supervised_loss
```
When `cotraining_loss` weight is too high, it creates "label confusion" between ground truth and pseudo-labels generated by cross-domain predictions.
