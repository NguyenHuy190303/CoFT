# THESIS WRITING GUIDE: SECTION 6 - REFERENCES AND APPENDICES

This final section is for acknowledging the sources used and providing supplementary information that doesn't fit well within the main chapters.

---

### 6.1. References / Bibliography

**Purpose:**
To list all academic sources (papers, books, technical reports, etc.) that you have cited in your thesis. This is a mandatory requirement to ensure academic integrity, avoid plagiarism, and allow readers to find the original sources.

**Required Content:**
- **Complete List:** Every in-text citation (e.g., [Author, Year] or [1]) must correspond to an entry in this list, and vice versa.
- **Consistent Formatting:**
    - Adhere to a single citation style required by your university or department.
    - Common styles in engineering and computer science include:
        - **IEEE (Institute of Electrical and Electronics Engineers):** Uses numbers in square brackets, e.g., [1].
        - **APA (American Psychological Association):** Uses (Author, Year).
        - **ACM (Association for Computing Machinery):** Similar to IEEE.
- **Use a Citation Management Tool:**
    - It is highly recommended to use tools like Zotero, Mendeley, EndNote, or BibTeX (if using LaTeX).
    - These tools help you automate the creation of the reference list and ensure consistent formatting, saving a great deal of time and effort.

**Example of an IEEE style reference entry:**
`[1] C. Chen, M. Zhang, W. Ma, Y. Liu, and S. Ma, "Efficient Non-Sampling Factorization Machines for Optimal Context-Aware Recommendation," in The Web Conference 2020 (WWW '20), 2020, p. 11.`

---

### 6.2. Appendices

**Purpose:**
To provide supplementary information, details, or original materials that would disrupt the flow if included in the main chapters. Appendices are optional.

**What to include in an Appendix:**
- **Large Source Code Snippets:**
    - If you have a particularly important and complex piece of code (e.g., an algorithm you implemented yourself), you can include it here. You should not include the entire project's source code.
- **Detailed Data Tables:**
    - Results tables that are too large or too detailed for Chapter 4.
- **Mathematical Proofs:**
    - Lengthy proofs for theorems or formulas mentioned.
- **Additional Survey/Interview Information:**
    - If you conducted a survey, you could include the full questionnaire here.
- **Additional Figures:**
    - Relevant figures or diagrams that are not essential to the main argument.

**Rules:**
- Each appendix should be clearly labeled (e.g., Appendix A, Appendix B).
- Each appendix should have a title describing its content (e.g., Appendix A: Source Code for ABC Algorithm).
- If you have an appendix, you should refer to it somewhere in the main text (e.g., "Details of the algorithm implementation are presented in Appendix A.").
